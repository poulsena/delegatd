# Security Policy

## Reporting a vulnerability

Please use GitHub’s **private vulnerability reporting** feature from the repository Security tab. Do not disclose vulnerabilities in public issues, pull requests, or comments. Include the affected commit, reproduction steps, impact, and any safe mitigation details; never include live credentials or private keys.

## Supported line

`main` is the only supported pre-release line. Security fixes are evaluated against the current `main` branch; no older release line is supported before the first stable release.
